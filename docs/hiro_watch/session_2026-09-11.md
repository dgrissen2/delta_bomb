## Mark defect found and fixed (affects every MTM quoted before 2026-09-11)

`book()` marked each leg at its own last valid minute ≤ close, so the two legs could come from different
times; three bombs were priced BELOW zero (−$130, −$200, −$200), which a long put vertical cannot be.
Fixed: `MarkCache.spread_mid()` requires both strikes to have a valid quote in the SAME minute and the
value is clamped to [0, width] (2 tests). Corrected inventories: v1 +1,530 (was +1,000), pick +1,075
(was +945), pull8 +1,075 (was +945).
